# Frontend Design & UI Consistency

Ensures Promii maintains a cohesive product identity.

## Rules

- Follow existing design tokens (COLORS).
- Avoid inline style overrides.
- Reuse existing components instead of duplicating UI logic.
- Avoid layout shift (LCP stability).
- Keep button states consistent (hover, active, disabled).
- Maintain responsive layout.
- Avoid introducing new UI libraries.
- Prefer composable components.
- Avoid mixing design systems.
- Ensure dashboards maintain visual hierarchy.
